# Когда дешёвый предиктор улучшает распределение вычислений?

Карта создана 2026-11-02. Это наша организация направления, а не обзор литературы
с исчерпывающим охватом.

## Вопросы для накопления свидетельств

| Вопрос | Что сравнивать |
| --- | --- |
| Может ли отбор быть дешевле выполнения? | Полная стоимость обучения, оценки и проверки предиктора |
| Сохраняется ли качество при смене домена? | Среднее качество, худшие группы, уверенные ошибки |
| Помогает ли обратная связь? | Замороженный предиктор против обновляемого при одинаковом бюджете |
| Есть ли долгосрочный ущерб от отбора? | Покрытие редких задач, динамика ошибок, достижимое качество |

## Источники и очередь

- [Концептуальная работа](../../../papers/2026/arxiv-2610.39497/review.md) — частично прочитана.
- [MoPPS](../../../papers/2025/arxiv-2507.04632/review.md) — сверена часть таблицы результатов.
- [GPS](../../../papers/2026/arxiv-2602.01970/review.md) — следующий кандидат для подробного чтения.

## Состояние направления

Наше текущее покрытие слишком узко для вывода о всей области. Нужны независимые
группы, отрицательные результаты и работы с новыми доменами. Совпадение терминов
System-1 не гарантирует одинаковой постановки.

## Кандидат исследования

[Независимый аудит при смене домена](../../ideas/idea-domain-shift-audit/review.md).
Перед экспериментом провести поиск близких методов и возможных уже известных решений.

## Смежная работа: R²Orch

[R²Orch](../../../papers/2026/arxiv-2610.22740/review.md) соединяет подбор задач
с постепенным снятием внешних инструкций у обучаемого оркестратора. Для нашего
направления интересны рандомизированные проверки полезности инструкций и различие
между управляемой вариативностью решений и шумом Workers. Это аналитическая связь:
сравнения с MoPPS/GPS в одинаковых условиях пока нет. Начальные skills ручные,
Proposer выбирает из существующих задач. Вопрос независимого аудита остаётся открытым.
