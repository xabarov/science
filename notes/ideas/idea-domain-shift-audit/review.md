# Бюджет независимого аудита предиктора при смене домена

Идея предложена ассистентом 2026-11-02. Пользователь её не утверждал.
**Новизна не проверена; эксперимент не проводился.** Это кандидат направления.

## Гипотеза

Меняя долю независимых проверок по внешним признакам сдвига распределения,
можно улучшить качество при том же полном бюджете по сравнению с фиксированной
долей аудита. Уверенность самого предиктора может быть недостаточным сигналом.

## Минимальный эксперимент

Взять фиксированного исполнителя и задачи с объективным проверяющим ответом.
Провести контролируемый переход от знакомых задач к новому домену, сохраняя
отложенную выборку с полной оценкой всех кандидатов. Сначала offline replay;
затем, если есть эффект, эксперимент с обновлением предиктора.

Сравнить: выполнение всех задач; отбор без аудита; фиксированный случайный аудит;
проверку только по неопределённости; адаптивный аудит с ненулевой случайной долей.
Все методы сравнивать при одинаковом полном бюджете, включая обучение предиктора.

Метрики: точность исполнителя, пропуск полезных действий, качество худшей группы,
калибровка, стоимость, задержка и время восстановления после сдвига. Несколько
случайных запусков, доверительные интервалы, чувствительность к величине сдвига.

## Критерий опровержения

При равном бюджете адаптивный аудит не улучшает заранее выбранную метрику
относительно фиксированного аудита либо расход на обнаружение сдвига съедает
выигрыш. Заранее определить допустимую потерю качества и порог эффекта.

## Следующий шаг

OOD detection и adaptive auditing. Затем выбрать одну задачу и измерить стоимость
полной оценки. Это ещё не проект с подтверждённой новизной.
