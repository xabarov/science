# Первоисточники и резервные копии

## Снимки

```sh
python3 science.py snapshot arxiv:2610.39497 --url https://arxiv.org/html/2610.39497v1 --version v1
python3 science.py check-sources --require-files
```

Поддерживаются HTML/plain text, до 50 MiB. Сохраняются исходные байты, извлечённый
текст, URL до/после переадресации, версия, время и SHA-256 обоих файлов.
`sources/manifest.json` хранится в Git. Полные тексты находятся в `attachments/`
и не публикуются на GitHub. Повторный идентичный снимок не дублируется; изменение
байтов создаёт другой хеш. Указанная версия — метка пользователя, не доказательство
подлинности страницы. Парсер извлекает текст для поиска; формулы и таблицы надо
проверять по исходному HTML.

В новом клоне `check-sources` сообщает not_downloaded; строгий режим требует
наличия локальных файлов. Чтобы точно восстановить прежние байты, использовать
резервную копию: повторное скачивание по тому же URL может дать другой хеш.

## Резервная копия и восстановление

```sh
python3 science.py backup --destination /path/outside/repository
python3 science.py verify-backup /path/science-TIMESTAMP.tar.gz
python3 science.py restore /path/science-TIMESTAMP.tar.gz --to /path/new-science
cd /path/new-science
python3 science.py index
```

Архив содержит карточки, код, документацию, тесты, манифесты, вложения и Git bundle
при наличии коммитов. Кэш моделей, SQLite, .venv, .git, exports и .env исключены.
Каждый файл проверяется по SHA-256; дополнительно создаётся хеш всего архива.
Restore проверяет архив, запрещает обход путей/ссылки и работает только в новый каталог.
Git-историю можно отдельно получить из history.bundle. Существующая рабочая папка
не перезаписывается. Символические ссылки не включаются в резервную копию.

На рабочем Mac настроено ежедневное локальное резервирование в 23:30 через launchd;
путь и журнал задаются установщиком `install_backup.py`. Настройка не переносится
автоматически при клонировании. Публикация Git на GitHub сохраняет удалённую копию
коммитов, но **вложения остаются только локально**. Для защиты от потери диска
скопировать архивы на другой носитель или задать такой носитель как destination.
Место хранения и срок хранения архивов нужно контролировать; автоматического удаления нет.

```sh
python3 install_backup.py --destination /path/to/backups
```

Установщик заменяет только собственный launchd job `com.xabarov.science.backup`.
Задача резервирует локальные файлы; она не читает новые статьи и не публикует изменения.
