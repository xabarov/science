# Архитектура

## Реализованные слои

| Слой | Хранение и поведение |
| --- | --- |
| Исходные записи | record.json + review.md, Git |
| Источники | неизменяемые снимки по SHA-256, отслеживаемый манифест |
| Картотека | SQLite FTS5/BM25, термины, фильтры, aliases |
| Исследование | question/idea/experiment, утверждения, измерения, novelty_checks |
| Зависимости | точные ссылки на утверждения, хеши принятых оснований, очередь пересмотра |
| Семантический поиск | локальный E5, токенные фрагменты, точный cosine, опциональный RRF |
| Граф | связи документов в SQLite, экспорт документов/понятий/утверждений в Neo4j |
| Резервирование | проверяемые архивы с исходниками/вложениями/Git bundle, launchd |
| Проверки | unit tests + GitHub Actions на Python 3.9/3.12 |

Ядро не требует сетевого сервера. Для воспроизводимости optional Python-окружение
закреплено requirements-semantic.txt, версия модели — конкретным SHA. Полные тексты
не загружаются в сервис эмбеддингов: кодирование выполняется локально.

## Согласованность

index сначала валидирует все записи, затем обновляет SQLite одной транзакцией.
Ошибочная запись сохраняет прошлый рабочий индекс. check сравнивает fingerprint.
Семантический индекс строится во временном файле и заменяется атомарно; неизменившиеся
фрагменты используют прежние векторы. Сигнатура учитывает карточки, словарь и доступные
снимки, если включён --with-sources. Снимки проверяются по хешам перед индексацией.

Новые исследовательские поля находятся в extra.research, без миграции исходного
формата v1. Claim ID стабилен в пределах документа. Ссылки на отсутствующие локальные
утверждения и циклы зависимостей блокируют validate. Циклическое цитирование допустимо.
Изменение основания отмечает зависимые записи, но не утверждает, что они неверны.

## Проверки масштаба и качества

В первой версии, 2026-11-02, временный корпус из 36 500 синтетических записей с
review.md примерно по 3 КБ индексировался FTS за 8,09 с; SQLite занимал 245,43 МиБ.
Поиск общего слова: медиана 91,65 мс, максимум 92,77 мс по 12 запросам.
Это тест коротких однотипных заметок, не полного корпуса статей и не семантического слоя.

Поисковый набор текущего исследовательского слоя: 8 вручную размеченных запросов,
10 документов. [Полные результаты](search-evaluation.json). Набор предназначен для
разработки; необходимы независимые запросы и больше нерелевантных работ. Сравниваются
исходный лексический AND, лексический OR, semantic и hybrid. Гибрид не предполагается
лучшим заранее и остаётся отдельным режимом.

## Следующие расширения по измеренной потребности

- Инкрементальная индексация исходных записей: сейчас FTS пересобирается целиком.
- ANN и cross-encoder при росте количества фрагментов: сейчас матрица в памяти.
- Русская лемматизация и более аккуратное извлечение формул/таблиц, OCR.
- Автоматическое обнаружение новых версий/исправлений статей; сейчас снимок добавляется явно.
- Автоматический импорт библиографии, ORCID и разрешение однофамильцев.
- Сервер Neo4j для интерактивных графовых запросов; экспорт уже включает claim-узлы.
- Несколько пользователей: очередь писателей или серверная БД при фактической необходимости.

Резервирование и восстановление описаны в [preservation.md](preservation.md).
Проверки структуры не заменяют научное рецензирование. Novelty log документирует
границы поиска; отсутствие найденной работы не доказывает новизну.
