# Поиск по смыслу

Опциональный слой: Python 3.12, локальная модель intfloat/multilingual-e5-small.
Версия весов закреплена SHA в semantic.py. Ядро картотеки работает без этих зависимостей.

```sh
uv venv --python python3.12 .venv
uv pip install --python .venv/bin/python -r requirements-semantic.txt
python3 science.py index
.venv/bin/python science.py semantic-index --with-sources
.venv/bin/python science.py semantic-search 'как обнаружить уверенные ошибки в новой предметной области' --hybrid --limit 5
.venv/bin/python science.py eval-search --k 3
```

При первом запуске скачиваются веса; текст кодируется локально на CPU. Индекс
содержит нормализованные векторы размерности 384, модель, SHA версии, хеши текстов,
локаторы фрагментов и время построения. Используются префиксы `query:`/`passage:`
согласно [карточке E5](https://huggingface.co/intfloat/multilingual-e5-small).
Модель загружается через [Sentence Transformers](https://www.sbert.net/docs/package_reference/sentence_transformer/model.html)
с trust_remote_code=false.

Фрагменты ограничены 400 токенами с перекрытием 60 токенов. Индексируются метаданные,
разборы и утверждения. `--with-sources` добавляет доступные проверенные снимки
первоисточников; locator указывает файл и строку извлечённого текста. Поисковое
совпадение в полном тексте не означает, что статья полностью разобрана.
Повторное построение переиспользует векторы неизменившихся фрагментов. Изменение
исходных записей делает индекс устаревшим: поиск требует пересборку.

Поиск — точное косинусное сравнение, затем лучший фрагмент каждой записи.
`--hybrid` объединяет ранжирование с лексическим OR-поиском через reciprocal rank
fusion. Это объединение рангов, отдельного cross-encoder reranker пока нет.
Запрос в исходном search использует AND; сравнение с ним показывает разницу
пользовательского поведения целиком, не изолированный вклад embeddings.

Набор evals/search-queries.json содержит русские и английские запросы с явными
relevant ID. eval-search выводит Recall@k, MRR@k и nDCG@k, результаты каждого запроса
и хеш набора. Это маленький набор для разработки, а не независимый benchmark.
Добавляйте трудные запросы и нерелевантные статьи до выводов о качестве на всей области.
Итог локальной проверки сохранён в docs/search-evaluation.json.

На большом корпусе нужно измерить память и задержку: текущая реализация загружает
матрицу фрагментов в память. Масштабный тест первой версии относился только к FTS,
а не к embeddings. ANN и отдельный reranker добавляются по измеренной необходимости.
