# Поиск по смыслу: OpenRouter + Qdrant

Модель по умолчанию — [baai/bge-m3](https://openrouter.ai/baai/bge-m3),
мультиязычные dense-векторы размерности 1024. Используется
[OpenRouter Embeddings API](https://openrouter.ai/docs/api/api-reference/embeddings/create-embeddings).
Sparse- и ColBERT-представления BGE-M3 не задействованы. Тексты карточек,
выбранных снимков и поисковые запросы отправляются провайдеру через OpenRouter.
Вектора и фрагменты хранятся в локальном сервере Qdrant.

## Запуск

Требуются Python 3.9+ и Docker Compose. Python-пакеты и веса моделей устанавливать
не нужно; прежняя `.venv` с локальной E5 больше не используется.

```sh
cp .env.example .env
chmod 600 .env
# Заполните OPENROUTER_API_KEY в редакторе; не выводите ключ в терминал.
docker compose up -d
python3 science.py index
python3 science.py semantic-index --with-sources
python3 science.py semantic-search 'как обнаружить уверенные ошибки в новой предметной области' --limit 5
python3 science.py semantic-search 'adaptive auditing' --hybrid
python3 science.py semantic-status
```

На исходном Mac `.env` уже заполнен. При повторном запуске его не перезаписывать.
Формат `.env`: буквальные `KEY=value`, необязательные кавычки вокруг значения,
комментарии отдельной строкой. Shell-команды и подстановка переменных не исполняются.
Переменные окружения имеют приоритет. Ключи исключены из Git и резервных архивов;
`.env.example` содержит только пустые значения и настройки по умолчанию.

Qdrant закреплён на версии 1.20.0 и слушает только `127.0.0.1:6333`.
[Dashboard](http://127.0.0.1:6333/dashboard). Хранилище: `data/qdrant/`,
сохраняется при пересоздании контейнера. `docker compose stop` останавливает сервер,
`docker compose up -d` запускает. `restart: unless-stopped` действует при запущенном
Docker; Docker Desktop должен запускаться вместе с системой, если поиск нужен сразу.
Ключ OpenRouter в контейнер не передаётся.

Можно указать внешний `QDRANT_URL` и `QDRANT_API_KEY` в `.env`. Для внешнего сервиса
нужны HTTPS и авторизация; публично открывать локальный compose не следует.

## Индексация и согласованность

- Индексируются метаданные, разборы и утверждения. `--with-sources` добавляет локальные
  снимки, прошедшие проверку хешей. Результат содержит документ, источник и локатор
  файла/строки; совпадение в снимке не означает полного разбора статьи.
- Фрагменты — до 2000 Unicode-символов, перекрытие 200 символов. Это символьное,
  а не токенное разбиение. У BGE-M3 не добавляются префиксы E5 `query:`/`passage:`.
  Поисковый запрос также ограничен 2000 символами, без молчаливого усечения.
- API получает пакеты до 16 текстов. Повторы при 429/временных 5xx ограничены тремя
  попытками. Неверные размерности, NaN, нулевые векторы и неполные ответы отклоняются.
- `data/embedding-cache.sqlite3` хранит эмбеддинги по хешу текста и настройкам
  модели. Кэш действует между запусками и после неудачной сборки. SQLite здесь
  служит кэшем API; поиск выполняет Qdrant.
- Новое поколение загружается в отдельную коллекцию. После проверки числа точек и
  неизменности исходников [alias переключается атомарно](https://qdrant.tech/documentation/manage-data/collections/#collection-aliases).
  Частичная загрузка не заменяет рабочий индекс. `<alias>_previous` сохраняет
  предыдущее поколение. Два писателя из одного checkout блокируются локальной блокировкой.
- Полный fingerprint учитывает записи, словарь, снимки и режим их включения.
  Изменившиеся исходники или модель требуют `semantic-index`. Неизменившийся индекс
  повторно не загружается. Модель автоматически на запасную не переключается.
- `EMBEDDING_MODEL`, `EMBEDDING_DIMENSIONS` и `EMBEDDING_VERSION` образуют пространство
  векторов. При смене модели укажите её реальную размерность; новая коллекция будет
  создана отдельно. Если провайдер изменил веса под тем же именем, увеличьте VERSION.
  Веса API не закреплены SHA, побитовая воспроизводимость провайдера не гарантируется.
  Текущая предобработка рассчитана на BGE-M3; для моделей с инструкциями нужны правки.

Qdrant использует cosine и HNSW, выбирая сканирование для небольших сегментов.
[Группировка по документу](https://api.qdrant.tech/api-reference/search/query-points-groups)
возвращает лучший фрагмент каждого документа; матрица всех векторов в CLI не загружается.
`--hybrid` объединяет ранги Qdrant и SQLite FTS OR через RRF. Это не reranker.

## Обслуживание

```sh
python3 science.py semantic-status
python3 science.py semantic-index --with-sources
python3 science.py semantic-prune
```

`semantic-prune` удаляет старые завершённые поколения этой картотеки, сохраняя все
коллекции с alias, включая текущую и предыдущую. Запускайте между поисковыми сессиями:
долго работающий Searcher фиксирует физическое поколение. После аварийного завершения
процесса может остаться незавершённая коллекция без манифеста; команда её не удаляет.
Разные checkout, пишущие в один alias, пока требуют внешней очереди писателей.

`data/` не включается в Git и стандартный backup. После восстановления исходников
нужно вернуть локальный `.env`, запустить Qdrant и пересобрать индекс; потеря кэша
означает повторные платные вызовы API. Старый `data/semantic.sqlite3` от E5 не читается.

## Оценка

```sh
python3 science.py eval-search --k 3
SCIENCE_TEST_QDRANT_URL=http://127.0.0.1:6333 python3 -m unittest discover -s tests -v
```

Интеграционные тесты используют настоящий Qdrant и искусственные эмбеддинги;
они не обращаются в OpenRouter и не требуют ключа. Реальная модель проверяется
через `eval-search`. В CI Qdrant запускается отдельным service container.

На текущих 8 размеченных запросах и 10 документах BGE-M3: Recall@3 = 1.00,
MRR@3 = 0.854, nDCG@3 = 0.899. Hybrid: Recall@3 = 0.8125, nDCG@3 = 0.706.
[Результаты BGE-M3](search-evaluation.json), [предыдущая E5](search-evaluation-e5.json).
Это маленький набор для разработки. Одновременно изменились модель и разбиение
текстов, поэтому сравнение относится ко всему поисковому контуру. Проверки ANN
recall, памяти и задержки на годовом корпусе ещё не проводились.
