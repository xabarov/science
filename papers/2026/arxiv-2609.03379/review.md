# RecurTrace как близкая работа по обучаемой остановке

Частичный разбор v3 от 19 октября 2026, проверка 2026-11-05. Проверены идея метода,
формула halting и выбранные ограничения; численные benchmark результаты здесь
не аудированы и эксперимент не воспроизводился.

RecurTrace повторяет блок слоёв frozen Qwen3, добавляя доступ к состояниям предыдущих
loops через Loop Memory Attention. Halting head получает pooled состояние и
предсказывает продолжение. Oracle ставит положительную метку, если более глубокое
вычисление уменьшает loss сверх margin; head обучается через BCE. Threshold
выбирается на held-out data. [Section 3, Eq. 6](https://arxiv.org/html/2609.03379v3#S3).

Это уже близко к нашей конструкции «обучаемый gate по hidden states и targets
добавочной полезности». Отличие RecursiveMAS — несколько разных LLM и межагентный
цикл. Такой перенос требует отдельных экспериментов, но не позволяет заявлять
новизну adaptive halting как принципа.

Важное различие для сравнения: RecurTrace обучает не только halting head, но и
loop/memory/injection components. Отсюда нельзя приписать весь эффект одному gate.
В Section 5.3 авторы ограничивают постановку sequence-level глубиной, frozen Qwen3
и direct-answer задачами; вывод для long-form generation остаётся открытым.
