# MoPPS — частичная проверка экспериментов

ID: `arxiv:2507.04632`. v2, 2026-11-02. Прочитаны выборочные разделы и Table 1;
это не полный разбор и не воспроизведение. Препринт 2025 года; обсуждаемый обзор
ссылается на публикацию KDD 2026.

Метод поддерживает байесовские оценки успеха отдельных задач и выбирает
информативные примеры. Это специализированный предиктор; Jev здесь не используется.

## Сверенные числа

DeepSeek-R1-Distill-Qwen-1.5B обучали на MATH. Метрика — средний pass@1
по 16 генерациям на задачу AIME24. [Table 1](https://arxiv.org/html/2507.04632v2#S4.SS2).

| Выбор задач | AIME24 | Rollout при обучении |
| --- | ---: | ---: |
| Uniform | 26,46% | 737 тыс. |
| Dynamic Sampling | 30,42% | 2 933 тыс. |
| MoPPS | 33,33% | 737 тыс. |

В §4.2.2 сообщается ускорение порядка 1,8× на Countdown/Geometry относительно
Uniform. Четверть rollout относительно DS — другая метрика, не четырёхкратное
ускорение по времени. Интервалы неопределённости этих чисел здесь не проверены.
